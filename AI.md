# AI Usage Guidelines

For general contribution guidelines, refer to our [contributing guidelines](CONTRIBUTING.md).

## Code Contributions

The usage of AI in CitrineOS is not prohibited, but we ask that contributors:

1. **Do not override** any rules specified in the repository's `AGENTS.md`.
2. Thoroughly review, understand, and locally run all code generated.
3. Ensure the compilation, correctness, security, and performance of the code generated.
4. Leave out unnecessary in-code comments generated by their AI agents.
5. Disclose that the code is AI generated in the resulting pull request (e.g. at the bottom of the description, add "Written by Claude Code 🤖", etc.).
6. Follow all project code standards and guidelines.

Pull requests that are suspected to be purely AI-written with no human in the loop will be closed without further review.

## Communications

Contributors may use AI to assist with communications such as PR descriptions, issues, and comments (e.g. for grammar checking), 
but we do not allow copy-pasted blocks of AI generated text. If humans are expected to review code and answer questions, 
then humans are expected to understand any ongoing discussions and communicate effectively.

Communications such as descriptions, issues, discussions, and comments that are suspected to be AI-written with no human 
in the loop will be ignored and removed without further review.

## Repeated Violations

Repeated violations of the guidelines above will result in restricted repository access.

## Additional Reading

As a Linux Foundation project, CitrineOS aligns with their generative AI policy. Please refer to it 
[here](https://www.linuxfoundation.org/legal/generative-ai).
